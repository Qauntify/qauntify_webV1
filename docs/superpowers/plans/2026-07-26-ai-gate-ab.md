# AI Gate A/B (Shadow Signals) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record LLM-rejected setups as outcome-tracked *shadow signals* that no user can ever see, so the confirmation gate's accuracy becomes measurable.

**Architecture:** One new boolean column on `signals`. Every read path that a user can reach is filtered to `shadow = false`; the outcome tracker alone continues to see them. The engine writes a randomly-sampled fraction of rejected setups as shadows.

**Tech Stack:** Python 3 / pytest, Supabase (PostgREST + RLS), Next.js/TypeScript for the read paths.

**Spec:** `docs/superpowers/specs/2026-07-26-ai-gate-ab-design.md`

---

## ⚠️ Read this before starting

**This plan modifies a production database and a live trading-signal engine.**

1. **Task 1 and Task 2 must land and be verified before Task 4.** Task 4 is the
   first code that writes a shadow row. If the RLS work is not proven first,
   the first shadow row is publicly visible — trades the system explicitly
   decided *not* to recommend, shown on a public track record.
2. **Do not skip Task 2.** It is the only step that proves the containment
   works, and it uses the anon key rather than trusting the policy text.
3. The service-role key **bypasses RLS entirely**. Any verification that uses
   it proves nothing about what the public can see. Task 2 uses `SUPABASE_ANON_KEY`.

### The full exposure surface

The design doc said "tighten the anon RLS policy." That was wrong — there are
**three** policies plus an aggregate function plus three web query sites. All of
them leak shadows unless changed:

| # | Path | Location | Leaks to |
|---|---|---|---|
| 1 | `anon preview access` — `created_at > now() - 24h` | `schema.sql:99` | anon, for a shadow's first 24h |
| 2 | `anon closed-trade access` — `status in (...)` | `schema.sql:353` | anon, forever, once closed |
| 3 | `member full access` — `using (true)` | `schema.sql:105` | every logged-in member |
| 4 | `get_signal_stats()` aggregate | `schema.sql:~130` | stats tiles |
| 5 | Track-record query | `web/src/lib/track-record.ts:194` | public page |
| 6 | Dashboard queries | `web/src/lib/signals.ts:118,176` | dashboard |
| 7 | Admin single fetch | `web/src/lib/supabase/admin.ts:456` | admin only — acceptable, leave |

The expiry job at `schema.sql:74` **must keep seeing shadows** — they need to
expire like any other signal.

## Task 1: Migration — shadow column and containment

**Files:**
- Modify: `supabase/schema.sql`

- [ ] **Step 1: Add the column**

Append to `supabase/schema.sql`:

```sql
-- Shadow signals: setups the LLM gate REJECTED, stored and outcome-tracked so
-- the gate's accuracy can be measured, but never shown to any user. They are
-- not recommendations; every user-reachable read path filters them out.
alter table public.signals
    add column if not exists shadow boolean not null default false;

create index if not exists signals_shadow_idx
    on public.signals (shadow)
    where shadow = false;
```

- [ ] **Step 2: Tighten all three policies**

```sql
drop policy if exists "anon preview access" on public.signals;
create policy "anon preview access"
    on public.signals for select
    to anon
    using (shadow = false and created_at > now() - interval '24 hours');

drop policy if exists "anon closed-trade access" on public.signals;
create policy "anon closed-trade access"
    on public.signals for select
    to anon
    using (shadow = false and status in ('tp_hit', 'tp3_hit', 'sl_hit'));

drop policy if exists "member full access" on public.signals;
create policy "member full access"
    on public.signals for select
    to authenticated
    using (shadow = false);
```

**Note:** RLS policies OR-combine. Leaving *any* policy unfiltered exposes
shadows regardless of the other two, which is why all three change together.

- [ ] **Step 3: Exclude shadows from the stats aggregate**

In `get_signal_stats()` (`schema.sql:~148`), change the final clause from:

```sql
    where p_timeframe is null or timeframe = p_timeframe;
```

to:

```sql
    where shadow = false
      and (p_timeframe is null or timeframe = p_timeframe);
```

**Files:**
- Create: `scripts/verify_shadow_rls.py`

- [ ] **Step 1: Write the verification script**

```python
"""Prove shadow signals are invisible to anon and member roles.

Inserts a shadow row with the service-role key, then reads back through the
ANON key — the only read that reflects what the public can actually see. The
service-role key bypasses RLS, so verifying with it would prove nothing.

Usage: python -m scripts.verify_shadow_rls
"""
import os
import sys
import uuid

import requests

REQUIRED = ("SUPABASE_URL", "SUPABASE_SERVICE_ROLE_KEY", "SUPABASE_ANON_KEY")


def main():
    env = {k: os.environ.get(k, "") for k in REQUIRED}
    missing = [k for k, v in env.items() if not v]
    if missing:
        sys.exit(f"missing env: {', '.join(missing)}")
    url = env["SUPABASE_URL"]
    svc = env["SUPABASE_SERVICE_ROLE_KEY"]
    anon = env["SUPABASE_ANON_KEY"]
    probe = str(uuid.uuid4())

    # Insert one shadow row in a CLOSED state, which is the worst case: it
    # matches both the 24h preview window and the closed-trade policy.
    row = {
        "id": probe, "symbol": "TESTUSD", "timeframe": "15m",
        "direction": "long", "entry": 100.0, "stop_loss": 99.0,
        "take_profit": 102.0, "confidence": 50, "rationale": "rls probe",
        "indicators": {}, "news_headlines": [], "status": "sl_hit",
        "shadow": True,
    }
    r = requests.post(
        f"{url}/rest/v1/signals", json=row, timeout=30,
        headers={"apikey": svc, "Authorization": f"Bearer {svc}",
                 "Content-Type": "application/json"},
    )
    r.raise_for_status()
    try:
        anon_hdr = {"apikey": anon, "Authorization": f"Bearer {anon}"}
        seen = requests.get(
            f"{url}/rest/v1/signals?id=eq.{probe}&select=id",
            headers=anon_hdr, timeout=30,
        ).json()
        leaked_direct = bool(seen)

        listed = requests.get(
            f"{url}/rest/v1/signals?select=id&limit=1000",
            headers=anon_hdr, timeout=30,
        ).json()
        leaked_listing = any(x.get("id") == probe for x in listed)

        stats = requests.post(
            f"{url}/rest/v1/rpc/get_signal_stats", json={"p_timeframe": None},
            headers={**anon_hdr, "Content-Type": "application/json"},
            timeout=30,
        )
        print(f"direct fetch leaked : {leaked_direct}")
        print(f"listing leaked      : {leaked_listing}")
        print(f"stats rpc status    : {stats.status_code}")
        if leaked_direct or leaked_listing:
            sys.exit("FAIL: shadow row is visible to anon")
        print("PASS: shadow row invisible to anon")
    finally:
        requests.delete(
            f"{url}/rest/v1/signals?id=eq.{probe}",
            headers={"apikey": svc, "Authorization": f"Bearer {svc}"},
            timeout=30,
        )


if __name__ == "__main__":
    main()
```

# Fraction of LLM-rejected setups stored as shadow signals for the gate A/B.
# Rejects arrive ~7x faster than confirms, and the confirmed arm is the
# statistical bottleneck, so sampling here costs no experiment time while
# keeping storage and outcome-tracker load roughly flat.
SHADOW_SAMPLE_RATE = float(os.environ.get("SHADOW_SAMPLE_RATE", "0.25"))

    """Random, and deliberately NOT keyed on confidence, symbol or strategy —

```python
"""Pre-registered analysis for the LLM confirmation-gate A/B.

Fixed in advance (see the design doc): primary metric is mean realised R under
the engine's scale-out model; test is a two-sided permutation test at
alpha = 0.05; stop at n = 250 per arm or 60 days.

Usage: python -m scripts.gate_report
"""
import os
import random
import statistics

from signals.backtest import scaled_r
from signals.storage import list_closed_signals

ALPHA = 0.05
TARGET_N = 250


def permutation_p(a, b, trials=20000, seed=7):
    """Two-sided p for the difference of means. Distribution-free, which
    matters because R-multiples are heavily skewed at these sample sizes."""
    observed = abs(statistics.mean(a) - statistics.mean(b))
    pool = list(a) + list(b)
    rng = random.Random(seed)
    hits = 0
    for _ in range(trials):
        rng.shuffle(pool)
        diff = abs(statistics.mean(pool[:len(a)])
                   - statistics.mean(pool[len(a):]))
        if diff >= observed:
            hits += 1
    return hits / trials


def realised_r(row):
    entry, stop = row.get("entry"), row.get("stop_loss")
    if entry is None or stop is None or entry == stop:
        return None
    tps = [row.get("take_profit"), row.get("take_profit_2"),
           row.get("take_profit_3")]
    tps = [t for t in tps if t is not None]
    if not tps:
        return None
    reached = sum(1 for k in ("tp1_hit_at", "tp2_hit_at", "tp3_hit_at")
                  if row.get(k))
    if row["status"] in ("tp3_hit", "tp_hit"):
        reached = len(tps)
    return scaled_r(row["direction"], entry, stop, tps,
                    min(reached, len(tps)), row["status"] == "sl_hit")


def main():
    url = os.environ["SUPABASE_URL"]
    key = os.environ["SUPABASE_SERVICE_ROLE_KEY"]
    rows = list_closed_signals(url, key, include_shadow=True)
    live = [r for r in rows if not r.get("shadow")]
    shadow = [r for r in rows if r.get("shadow")]
    a = [x for x in (realised_r(r) for r in live) if x is not None]
    b = [x for x in (realised_r(r) for r in shadow) if x is not None]

    print(f"confirmed (delivered): n={len(a)}  mean {statistics.mean(a):+.3f}R"
          if a else "confirmed: n=0")
    print(f"rejected  (shadow)   : n={len(b)}  mean {statistics.mean(b):+.3f}R"
          if b else "rejected: n=0")
    if len(a) < 2 or len(b) < 2:
        print("\nNot enough data yet.")
        return
    if min(len(a), len(b)) < TARGET_N:
        print(f"\nWARNING: smallest arm is {min(len(a), len(b))}, target is "
              f"{TARGET_N}. Reading the result now risks stopping on noise.")
    p = permutation_p(a, b)
    print(f"\ndifference: {statistics.mean(b) - statistics.mean(a):+.3f}R  "
          f"p = {p:.3f}")
    print("VERDICT:", "significant" if p < ALPHA else
          "NOT significant — the gate is neither proven to help nor to hurt")


if __name__ == "__main__":
    main()
```
